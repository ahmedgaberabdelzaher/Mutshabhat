# Review mutashabihat dataset (candidate)

Generated by `npm run build:mutashabihat` from the licensed sources in `assets/data/candidate/`. **Candidate data, not approved.** Used only by the `review` build flavor.

- HifzLink curated pairs (285) → `status: under_review`, `pilot: true`, `reviewCycle: QMT-49`.
- Waqar144 and Quranpedia groups → `status: draft`.
- Records with the same set of ayahs are merged into one (2,928 → 1,714), keeping every source in `attributions` (see docs/DATA_MODEL.md "De-duplication").
- Every group records its `source` (`hifzlink` / `waqar144` / `quranpedia`) and upstream `ref`.
- `highlightRules` are data-driven difference ranges (QMT-26). Auto-generated rules carry `source: auto_diff` and `status: draft`.
- Every pair/group has `similarityType` (`lafzi` / `semantic`); semantic = little shared wording and no shared ≥ 3-word phrase, hidden by default in the review build (except HifzLink pilot pairs) and never shipped to beta/production. Lafzi rules carry `method: lcs | phrase`. Rule: see `../README.md`.
- List titles (the similar phrase shown as each item's title) are data too: `highlightRules[].titles` (one exact Tanzil word span per side) and `groups[].title`, with `titleBasis` phrase / lcs / fallback / committee and `titleMethod` shared / extended / meaningful_word(_extended) / fallback (min. 2 words, particles don't count as shared). Rules: `docs/DATA_MODEL.md` → «List titles».
